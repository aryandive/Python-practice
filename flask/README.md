# Flask Static Site (Practice)

Minimal Flask project that serves static assets and Jinja2 templates.

Run (inside your virtualenv):

```powershell
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
python main.py
```

Open http://127.0.0.1:5000 in your browser. Pages:
- `/` home
- `/about`
- `/gallery` sample images
- `/contact` demo form
